The Core (Engine)

Impala Streamer uses the browser's native HTML5 media engine through standard <audio> and <video> elements. For HLS/live streams, it uses browser-native HLS where available and hls.js where needed. It does not use mpv, GStreamer, or FFmpeg as the playback engine.

Current Capabilities

Impala currently supports MP3, MP4, and FLAC playback. Local files can be served through the optional Impala Local Library Companion, which runs on the user's computer and provides an indexed music/video folder or USB attached drive to the web app. Impala also plays private cloud-hosted S4 media through signed URLs, playlists, and live/webcast streams. Direct stream URLs are supported through the Live Stream control surface when live streaming is enabled, though “paste any URL and play” is not the primary workflow. Additional features can be added over time, all optional. The modular architecture allows expansion without affecting the core experience.
